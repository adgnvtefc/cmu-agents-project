## Organizing downloaded files (receipts)
- Move to `/Expenses/{Month}`
- Rename to `{Vendor} - {Mon} {d}.pdf`
- Example: a Blue Bottle receipt dated 2026-11-12 → `Blue Bottle - Nov 12.pdf` in `/Expenses/November`

Use the receipt's own date (shown in the file preview), not today's date.
Create the folder first if it doesn't exist.
